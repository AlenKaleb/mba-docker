## Arquivo: `cap 09 - Montagem de imagens para produção/01 - Montagem de imagens para produção/python/Dockerfile`
```Dockerfile
FROM python:3.9.0-slim as builder

ENV PYTHONUNBUFFERED 1

RUN apt update && apt install --no-install-recommends -y libpq-dev gcc curl git zlib1g-dev libjpeg-dev && \
    pip install pdm

RUN useradd -ms /bin/bash python

WORKDIR /home/python/app

COPY pdm* pyproject.toml ./
RUN pdm export --format requirements --pyproject > /home/python/app/requirements.txt && \
    pip wheel -r requirements.txt --wheel-dir=/home/python/app/wheels

FROM node:20-slim as static

RUN mkdir /home/node/app
WORKDIR /home/node/app

COPY package*.json ./
RUN npm ci

COPY js/ ./js
COPY webpack.mix.js ./

RUN npm run prod && rm -rf node_modules

FROM python:3.9.0-slim

ENV PYTHONUNBUFFERED 1

RUN useradd -ms /bin/bash python

COPY --chown=python:python . /home/python/app
COPY --from=builder --chown=python:python /home/python/app /home/python/app
COPY --from=static --chown=python:python /home/node/app/static /home/python/app/static

RUN apt update && apt install --no-install-recommends -y nginx-light && \
    pip install --no-index --find-links=/home/python/app/wheels -r /home/python/app/requirements.txt && \
    chmod +x /home/python/app/.docker/start.prod.sh && \
    apt-get autoremove -y && \
    apt-get clean && \
    rm -rf /var/lib/apt/lists/* /home/python/app/wheels && \
    mkdir -p /var/log/nginx && \
    mkdir -p /var/log/gunicorn && \
    chown -R python:python /var/log && \
    mkdir -p /var/lib/nginx/proxy && \
    mkdir -p /var/lib/nginx/body && \
    mkdir -p /var/lib/nginx/fastcgi && \
    mkdir -p /var/lib/nginx/uwsgi && \
    chown -R python:python /var/lib/nginx && \
    chown -R python:python /etc/nginx/nginx.conf && \
    touch /run/nginx.pid && \
    chown -R python:python /run/nginx.pid && \
    sed -i '1d' /etc/nginx/nginx.conf

COPY .docker/nginx.conf /etc/nginx/sites-available/default

USER python
WORKDIR /home/python/app

ENTRYPOINT ["./.docker/start.prod.sh"]
```

### Anotações técnicas
- **Multi-stage**: `builder` gera wheels Python; `static` compila assets; estágio final une tudo.
- **PDM**: gerenciador de dependências para exportar `requirements.txt`.
- **Nginx + Gunicorn**: Nginx serve static e proxy para Gunicorn.
- **Hardening**: limpeza de caches e uso de usuário não-root.

## Arquivo: `cap 09 - Montagem de imagens para produção/01 - Montagem de imagens para produção/python/.docker/nginx.conf`
```nginx
server {
    listen 8080;
    access_log  /var/log/nginx/access.log;
    error_log  /var/log/nginx/error.log;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $http_host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    location /static {    
        autoindex on;    
        alias /home/python/app/static;
    }
}
```

### Anotações técnicas
- **Reverse proxy**: Nginx encaminha para Gunicorn na porta 8000.
- **Static files**: serve arquivos compilados em `/static`.

```bash
#!/bin/bash
exec gunicorn my_django.wsgi:application \
              --bind 0.0.0.0:8000 \
              --error-logfile /var/log/gunicorn/error.log \
              --access-logfile /var/log/gunicorn/access.log & \
     nginx -g 'daemon off;'
```

### Anotações técnicas
- **Processos**: inicia Gunicorn em background e Nginx em foreground.
- **Observabilidade**: logs separados para gunicorn e nginx.

"""Django's command-line utility for administrative tasks."""
import os
import sys


def main():
    """Run administrative tasks."""
    os.environ.setdefault('DJANGO_SETTINGS_MODULE', 'my_django.settings')
    try:
        from django.core.management import execute_from_command_line
    except ImportError as exc:
        raise ImportError(
            "Couldn't import Django. Are you sure it's installed and "
            "available on your PYTHONPATH environment variable? Did you "
            "forget to activate a virtual environment?"
        ) from exc
    execute_from_command_line(sys.argv)


if __name__ == '__main__':
    main()
